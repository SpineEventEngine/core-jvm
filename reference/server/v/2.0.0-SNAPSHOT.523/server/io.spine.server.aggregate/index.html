server/io.spine.server.aggregate

Package-level declarations

This package provides classes for creating and managing aggregates.

Since the event-sourcing cutover, an aggregate loads from its latest persisted state and keeps the events it produces as an append-only journal for traceability, rather than reconstructing its state by replaying them. See io.spine.server.aggregate.Aggregate.

class AggregateHistory : GeneratedMessage, AggregateHistoryOrBuilder, ValidatableMessage
The recorded history of an aggregate: the sequence of events it emitted.

Retained for wire compatibility; no longer produced or read by the runtime.
Since the event-sourcing cutover, aggregate state is no longer restored by
replaying the history, so the "snapshot plus tail" semantics of this message
no longer hold. The journal now stores plain `spine.core.Event`s directly,
with no dedicated wrapper type. The field-level comments below describe the
historical (pre-cutover) semantics.
